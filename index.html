SenHub Agent packages

Signed APT and YUM/DNF/Zypper repositories for the SenHub Agent on Linux (amd64 and arm64).

Editions

  • senhub-agent-oss: the open-source edition (Apache-2.0).
  • senhub-agent: the full edition, under the SenHub commercial licence; a licence key enables its paid probes.

The two editions install the same files and the same service: install one or the other. To switch, use sudo apt install senhub-agent on Debian and Ubuntu, sudo dnf swap senhub-agent-oss senhub-agent on RHEL and derivatives, or sudo zypper install --force-resolution senhub-agent on openSUSE and SLES (names exchanged to go back).

Channels

  • stable: final releases.
  • beta: pre-releases (X.Y.Z~beta.N), published before the final release.

Pick one channel per machine. The signing key fingerprint is B998 7A2D 4623 796E 19D3 B185 CA56 F750 3545 30AF; it is served at https://packages.senhub.io/gpg.key.

Channel stable

Debian, Ubuntu (apt)

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://packages.senhub.io/gpg.key | sudo gpg --dearmor --yes -o /etc/apt/keyrings/senhub.gpg
echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/senhub.gpg] https://packages.senhub.io/apt stable main" | sudo tee /etc/apt/sources.list.d/senhub.list
sudo apt update

sudo apt install senhub-agent-oss

sudo apt install senhub-agent

RHEL, Rocky Linux, AlmaLinux, Fedora (dnf)

sudo curl -fsSLo /etc/yum.repos.d/senhub.repo https://packages.senhub.io/rpm/stable/senhub.repo

sudo dnf install senhub-agent-oss

sudo dnf install senhub-agent

openSUSE, SLES (zypper)

sudo rpm --import https://packages.senhub.io/gpg.key
sudo curl -fsSLo /etc/zypp/repos.d/senhub.repo https://packages.senhub.io/rpm/stable/senhub-zypper.repo
sudo zypper refresh

sudo zypper install senhub-agent-oss

sudo zypper install senhub-agent

Packages and repository metadata are signed with the same key. Each client checks both: the repository metadata (repo_gpgcheck=1, or the signed InRelease for apt) and every package (gpgcheck=1).
